# GeoAI-Urban-Waterlogging-Dynamic-Risk-Assessment-Model
Built on the standard H-E-V framework, it integrates multi-source geospatial big data and GeoAI technologies, including MTW-DHAM, PF-DEAM and PF-DVAM modules, to achieve 250m grid, hourly resolution urban waterlogging dynamic risk assessment. Supports direct result reproduction and cross-city migration.
